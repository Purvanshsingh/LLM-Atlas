Step 1 · Tokens

From characters to token IDs

A model never sees letters. Text is split into tokens, and every distinct token gets an integer ID. Edit the text and compare three strategies. In BPE mode, drag the slider to learn merges one at a time and watch frequent fragments fuse into bigger tokens.

Sliding window → training examples

What one window teaches

The target is just the input shifted one token to the right. A single window of length n gives n next-token predictions at once. A stride smaller than the context makes windows overlap, so the same tokens get reused.

Step 2 · Attention

Who is each token looking at?

Every row is a token asking a question. Every column is a token that might answer. Cells show the attention weights after softmax, and each row sums to 1. Click a row to inspect it, then flip the switches and see what each piece of the mechanism does.

Step 4 · Sampling

Turning logits into the next word

The model outputs one raw score (a logit) per vocabulary entry. Temperature sharpens or flattens the distribution, and top-k cuts off the long tail. Sample many times to see that the observed frequencies (orange) match the probabilities (purple).
